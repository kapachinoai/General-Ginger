02Why it holds up

Built so points can't be farmed

  • Every flight is replayed on the server move by move before points count. Same seed, same inputs, same score, or nothing is saved. Bots and edited clients get nothing.
  • Daily caps: up to 300 points a flight and 1,500 a day, so no one can grind the airdrop pool overnight.
  • No wallet, no gas, no seed phrase to play. Anyone with a phone and slow data can join, which is how a game reaches millions of players instead of thousands of wallets.
  • A character, not a chart. The Ginger King, General Ginger and the Pest Battalion are an original cast from Lagos, made for memes, merch and more games.
